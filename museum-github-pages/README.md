# Бюро открытий — готово для GitHub Pages

Сайт на HTML, CSS и JavaScript. Посетителям не нужны вход, аккаунт ChatGPT или аккаунт GitHub. Все функции, иллюстрации и мини-игры работают в браузере.

## Как опубликовать

1. Создайте на GitHub публичный репозиторий (Public), например `museum`.
2. Откройте `Add file → Upload files`.
3. Загрузите **содержимое этой папки** в корень репозитория. Файл `index.html` должен быть виден сразу при открытии репозитория, рядом со `style.css` и `script.js`. Если используете ZIP, сначала распакуйте его.
4. Сохраните файлы кнопкой `Commit changes`.
5. Перейдите в `Settings → Pages`.
6. В `Source` выберите `Deploy from a branch`.
7. Выберите ветку с загруженными файлами (обычно `main`) и папку `/(root)`, затем нажмите `Save`.
8. Дождитесь успешной публикации. Ссылка появится в `Settings → Pages`.

Обычно адрес выглядит так: `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`. Открывайте и отправляйте именно ссылку GitHub Pages: простая загрузка файлов в репозиторий ещё не включает сайт.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Открыть на компьютере

Дважды нажмите на `index.html`. Установка программ и сборка не нужны.

## Файлы

- `index.html` — страница музея.
- `style.css` — оформление для компьютера и телефона.
- `script.js` — шесть экспонатов, три сборки, подсказки, блокнот идей и встроенные SVG-иллюстрации.
- `favicon.svg` — значок вкладки.
- `.nojekyll` — публикация обычных статических файлов.

Прогресс игры и идеи сохраняются в браузере посетителя. Для стабильного сохранения используйте опубликованный сайт; поведение localStorage при открытии файлов с компьютера зависит от браузера.

В исходном коде нет формы входа и переадресации на ChatGPT. Прежняя ссылка на домене chatgpt.site использует отдельные настройки хостинга. Эта папка работает самостоятельно на GitHub Pages.

## Где менять содержимое и оформление

- `index.html` — разделы страницы, заголовки и форма блокнота.
- `style.css` — цвета в начале файла, затем стили разделов. Правила для телефона находятся внизу, внутри `@media`.
- `script.js` — в `exhibits` лежат описания изобретений, в `blueprints` — детали чертежей. Ниже идут фильтры, окна, игра и сохранение заметок.
- `selectPart` выбирает деталь, `placePart` проверяет место, а `renderGame` обновляет чертёж и прогресс.

Основные части кода отмечены комментариями на русском. Для редактирования и запуска сборка не нужна.
